# Scripts

- `feedback-survey.gs`: Google Apps Script that creates the "Former Employee Workplace Survey" Google Form (terms page, six required consent boxes, screening question, ratings). Paste it into a new project at https://script.new and run `createSurvey` once. The form is a demo: it says on its first page that no one is contacted and no payment is made.

The app's own code is in `api/` and `lib/`. The web pages are in `public/`.
